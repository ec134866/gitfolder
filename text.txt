DAX vs M Query 
	⁃	M Query is the prep stuff, controls flow, variables, functions
	⁃	DAX is formulaic like excel (excel is cell based, DAX is column based)
	⁃	Not interchangeable, knowing one != knowing the other. Can do similar things. 
	⁃	Calculated columns (PBI) vs custom columns (PQ)
	⁃	Best practice = data cleaning in M Query, can add columns either way, keep it all in one place - that’s best practice, today not working M Query so I’ll show how to do in DAX
Calculated columns - processing days = DATEDIFF(ship date, order date, days)
Custom table (New Table) date table - CALENDAR(), Date, day of week, weekday num, week num, year, month
